# Skills Library

An accessible index of relevant Codex skills for this project.

| Skill | Description |
| --- | --- |
| `architecture-artifact-generator` | Turns textual software requirements into consistent Structurizr C4 models and PlantUML diagrams. |
| `hubspot-cms-modules` | Provides guidance for HubSpot CMS modules, HubL, React modules, fields, templates, and data fetching. |
| `initialize-software-project` | Creates or standardizes an evidence-oriented software project structure while preserving existing work. |
| `meeting-summary` | Turns transcripts and raw meeting notes into structured decisions, actions, risks, and open questions. |
| `regenerate-diagram-images` | Refreshes this project's generated diagram images after PlantUML or C4 DSL changes. |
| `render-puml-images` | Renders PlantUML source files as PNG, SVG, or PDF images. |
| `serve-structurizr-preview` | Starts a local browser preview of a Structurizr DSL C4 workspace. |
